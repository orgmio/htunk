# HTUNK

一款通用代理平台。

## N 有关名称

HTUNK，读音：/eɪtʃ.tʌŋk/。

这个名字是我看着键盘想出来的，并无明确的来历，
如果非要说的话，就是大脑中蹦出来的。
一开始我想叫htunc的，感觉十分的优雅：

- h可以让人联想到 high
- tun可以联想到隧道
- c可以联想到连接或者计算

后来因为最后的c有可能会造成读音不一致的问题
所以直接用了一点意大利办法，HTUNK，读音和拼写完美一致
不会产生歧义。

## 🛫 设计目标

htunk的目标旨在成为一个方便的，开箱即用的，兼容几乎一切平台的，高性能代理工具。
所以协议栈和配置文件格式目前已经确定为go语言配soml配置文件格式。

协议方面：
  计划支持市面上任何一种通用的代理协议，让您可以在一个客户端内完成您想做的几乎任何事情。
  同时取一些东西的精华，比如sing-box新增的sing-tun，他们的测试文章表明这东西快过任何一种tun实现，我自己测试也是如此，体感明显变快。
  所以htunk计划直接复用这种已经设计好的高雅工具。
  
  但是面对navieproxy或者wireguard怎么办？
  我觉得navie可以走CGO来调用chrome的C语言网络栈
  而wireguard，社区已经有wireguard-go这种实现了，我可以直接上。
